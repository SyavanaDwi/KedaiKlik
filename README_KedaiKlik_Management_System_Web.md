# KedaiKlik Management System Web

A web-based restaurant management system designed to help restaurant
staff and administrators manage daily operational activities through a
centralized dashboard.

## Overview

KedaiKlik Management System Web provides tools for managing restaurant
menus, monitoring incoming orders, updating order statuses, tracking
payments, and overseeing daily operations.

The application is developed to support a more organized restaurant
workflow by connecting the frontend with a backend RESTful API and a
relational database. Real-time communication is supported through
Socket.IO.

## Key Features

-   **Dashboard:** View an overview of restaurant operations.
-   **Menu Management:** Manage restaurant menu items.
-   **Order Management:** Monitor incoming customer orders.
-   **Order Status Updates:** Update order progress as it moves through
    the workflow.
-   **Payment Tracking:** Monitor payment information and order payment
    status.
-   **Real-Time Communication:** Receive and synchronize relevant
    updates using Socket.IO.

## Tech Stack

  Category                  Technologies
  ------------------------- ----------------------
  Frontend                  React.js, TypeScript
  Backend                   Node.js, Express.js
  Database                  PostgreSQL
  ORM                       Prisma ORM
  Real-Time Communication   Socket.IO

## Application Workflow

1.  Staff or administrators access the management application.
2.  Users view operational information through the dashboard.
3.  Staff manage menu data and monitor incoming orders.
4.  Order statuses and payment information are updated as needed.
5.  The application communicates with the backend API and database to
    keep operational data synchronized.
